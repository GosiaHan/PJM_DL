# README - Sign Language Recognition Model

## Used programming languages and tools
Python + Mediapipe
Dependencies and libraries: tensorflow, opencv-python, scikit-learn, numpy, pandas, pyarrow, tqdm, kaggle

---

## Workflow

1. Download train data from kaggle webpage -> https://www.kaggle.com/competitions/sign-language-recognition/data
2. Clean and prepare data  -> ```dataset_pjm/sign_name/*.npy```
2. Train model -> ```python train_lstm.py --classes "sign1,sign2,sign3"```
3. Record or download video with sign
4. Run prediction -> ```python predict_signs.py --source "video.mp4"```

---

## System requirements
- Python >3.11
- Windows 10/11
- GPU not required — works on CPU

1. Register/login at https://www.kaggle.com/account/login

3. Download data for model training by running script below:

```powershell
kaggle auth login

unzip asl-signs.zip -d asl_signs/
python load_asl_google.py
```

## 2. Training script = `train_lstm.py`

### How it works?

1. Reads sequence `.npy` from `dataset_pjm/` folder
2. Separates data into trening / validation / test
3. Trains LSTM model with 5-fold validation (K-Fold)
4. Saves model as `pjm_lstm_model.keras`
5. Saves class map as `label_map_pjm.json`
6. Generates plots into `plots/` folder

Examples of plots are to be seen in `examples` folder.

### Commands

**Train based on every sign/word in dataset:**
```powershell
python train_lstm.py
```

**Train on only specific signs/words:**
```powershell
python train_lstm.py --classes "apple,dog,fish,cry,dance"
```

**Train on first N signs/words (alphabetically):**
```powershell
python train_lstm.py --num-classes 10
```

**Change list of epochs and/or batch size:**
```powershell
python train_lstm.py --epochs 50 --batch 64
```

**Train based on specific classes and/or set custom folder (with data):**
```powershell
python train_lstm.py --data "C:\my_data" --classes "dog,cat,fish"
```

**Force data reload (ignore cache):**
```powershell
python train_lstm.py --refresh-cache
```

**Do not use cache completely:**
```powershell
python train_lstm.py --no-cache
```

### Every custom parameter available in script

| Parameter | Default | Description |
|---|---|---|
| `--data` | `dataset_pjm` | Data folder `.npy` |
| `--classes` | `all` | List of words, separated by comma, e.g. `"apple,dog,fish"` |
| `--num-classes` | `0` (all) | How much classes should be passed into train model (first N-number alphabetically) |
| `--epochs` | `10` | Max epochs amount |
| `--batch` | `32` | Batch's size |
| `--cache` | disabled | Use cache for faster loading |
| `--no-cache` | — | Disable cache |
| `--refresh-cache` | — | Reload data and cache |

### Training results

After script finish `plots/` folder should contain:
- `training_history.png` — plots of model losses and accuracy
- `confusion_matrix.png` — confusion matrix
- `confusion_matrix_normalized.png` — normalized confusion matrix

## 3. Prediction script – `predict_signs.py`

### How it works?

1. At first run automatically downloads hand detection model (~25 MB)
2. Opens selected video (user may select `fish.mp4` file from `examples` folder if want to do so)
3. For every frame detects hand and point 63 features (hand landmarks)
4. Buffers 30 clips and runs LSTM model
5. Display predicted sign on screen
6. Video loops automatically

### Commands

**Default command:**
```powershell
python predict_signs.py --source "C:\path\to\video.mp4"
```

**Change treshold (default 0.5 = 50%):**
```powershell
python predict_signs.py --source "C:\path\to\video.mp4" --threshold 0.7
```

**Save video with result and predictiond overlayed**
Zapisz wynikowy film z nałożoną predykcją:**
```powershell
python predict_signs.py --source "C:\path\to\video.mp4" --save "result.mp4"
```

**Every listed option at once:**
```powershell
python predict_signs.py --source "C:\path\to\video.mp4" --threshold 0.6 --save "result.mp4"
```

### Every prediction parameters

| Parameter | Default | Description |
|---|---|---|
| `--source` | *(required)* | Path to video file |
| `--threshold` | `0.5` | Minimal treshold - yellow text is below, green text is above |
| `--save` | empty | If provided, saves video with prediction as `.mp4` file inside folder |

### What is shown on screen

- **Top bar** - predicted sign (green = completely certain, yellow = uncertain)
- **Accuracy bar** - percentage of model certainty
- **Bottom bar** - buffer filling (30 clips needed for prediction) and FPS
- **Green skeleton** - detected hand landmarks
